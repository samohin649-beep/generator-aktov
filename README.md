# Передача фронта работ — приложение

Сайт приложения (PWA) для подачи заявок на передачу фронта работ подрядчиками и согласования застройщиком.
Данные, проекты актов и акты хранятся в Google Таблице и на Google Диске объекта; сайт обращается к веб-приложению Apps Script этой таблицы.

## Состав
- `index.html` — страница приложения
- `config.js` — список объектов: название и адрес веб-приложения Apps Script (`/exec`)
- `css/app.css`, `js/app.js` — оформление и логика (без сборки)
- `sw.js`, `manifest.webmanifest`, `icons/` — установка на телефон как приложение

## Новый объект
1. Копия таблицы объекта с проектом Apps Script (Реестры 2.4.5+, Форма 1.3+, Api 1.0+).
2. В таблице: меню «Реестры подрядчиков» → «Веб-приложение: настройка», заполнить лист «Застройщик».
3. Опубликовать веб-приложение (доступ: все), скопировать адрес `/exec`.
4. Добавить объект в `config.js`. Ссылка для объекта: `…/?o=<id>`.

Версия сайта 1.1 от 29.10.2026: согласующий от застройщика (корпус и направление), «Мои / Все», заявки на подключение организаций.
